# Data Analyst Portfolio

A modern responsive portfolio website built for a Data Analyst professional.

## Features

- Responsive design
- Dark modern UI
- About, Skills, Projects, Experience, Education sections
- Interactive layouts
- Contact section

## Built With

- React
- Vite
- CSS3
